01

任务瓶颈与核心动机

Motivation

类间混淆 · Inter-class Confusion

语义不同的异常共享「底层视觉基元」：纵火 ↔ 爆炸（火焰、烟雾），袭击 ↔ 斗殴（肢体冲突）——视觉特征彼此交织，类间边界模糊。

类内差异大 · Intra-class Variation

同类异常跨场景外观与尺度迥异：纵火既可能是角落里的纸团小火，也可能是开阔区域整辆车的剧烈燃烧。

核心观察：细粒度单类正样本有限，但「正常 / 异常」二值标注通用且充足 → 提出渐进式跨粒度学习，由粗到细引导特征空间演化。

03

三级跨粒度学习机制

Method
1

Coarse Level

建立通用异常空间
  • 文本锚点 [Normal; Anomaly]，对齐图 Mcoarse ∈ ℝn×2
  • 损失：二值交叉熵 ℒbce + InfoNCE 对比损失 ℒcts
  • 作用：平抑类内差异，构建统一的异常表征基底
2

Intermediate Level

伪宏类结构先验
  • 仅对 M 个异常类文本嵌入做 K-Means（K=4），与 Normal 拼接为 K+1 个原型
  • 以 Mcoarse 为 Query 注意力注入，更新为 Ẽpseudo → Minter
  • 无显式损失：软结构正则 + 提供宏类先验 Cp(i)
3

Fine Level

化解类间混淆
  • 注意力引导得到精细对齐图 Mfine ∈ ℝn×(M+1)
  • Top-T（T=16）多示例池化 → 类别级分数 s
  • 同宏类加权交叉熵 ℒrefine：ω > 1 加重惩罚
REFINEMENT LOSS
ℒrefine = − 1N Σi=1N Σj=0M αi,j yi,j log si,j
αi,j = ω > 1（同宏类）｜1（其他）—— 强化「同族相近类别」之间的区分
推理：某帧与异常类相似度高于阈值 σ 判为该类，全部低于 σ 判为正常

1损失设计的可迁移性

「粗级对比聚流形 + 中间层无损失软引导 + 细级同簇加权交叉熵」——这套应对弱监督类别稀疏的组合策略，可直接尝试迁移到组内弱监督 / 开集异常检测 Baseline。

2聚类中心的动态化

本文宏类划分依赖离线的文本 Prompt K-Means，而文本先验与视频视觉特征存在域差；可探索多模态对齐或最优传输（OT），实现视觉-文本动态自适应聚类。

3多标签复合异常

方法预设每段视频仅含一种主导异常；真实安防中「车祸 + 起火」等复合事件常见。单路径跨层级注意力如何扩展为多标签并发检测，是值得深入的研究切入点。
